# GB/T 35273-2020 信息安全技术 个人信息安全规范

## 概要

国家标准，规定个人信息收集、存储、使用、共享、转让、公开披露等环节的安全规范。

## 与 PrivShield 的对应关系

| 规范要求 | PrivShield 实现 |
|---|---|
| 个人信息去标识化 | MaskingApi (数据脱敏) |
| 个人信息匿名化 | KAnonymityApi (K-匿名化) |
| 统计发布隐私保护 | DpApi (差分隐私) |
| 数据分类分级 | DynClassificationEngine |
| 审计追溯 | AuditLogger |

## 关键条款

- 第 5.3 条：个人信息控制者应建立分类分级制度
- 第 6.1 条：收集个人信息应遵循最小必要原则
- 第 7.4 条：共享个人信息前应去标识化
- 第 8.2 条：公开披露个人信息应匿名化处理
