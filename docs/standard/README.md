# 标准规范

> PrivShield Java 遵循的国内外数据安全分类分级标准。

## 国家标准

| 标准 | 说明 |
|------|------|
| GB/T 43697-2024 | 数据安全技术 数据分类分级规则 |
| GB/T 35273-2020 | 信息安全技术 个人信息安全规范 |

## 行业标准

| 标准 | 说明 |
|------|------|
| JR/T 0197-2020 | 金融数据安全 数据安全分级指南 |

## 地方标准

| 标准 | 说明 |
|------|------|
| 广东省健康医疗数据安全分类分级管理技术规范 | 广东医疗健康领域 |
| 四川省健康医疗大数据应用指南 | 四川医疗健康领域 |

## 分类级别映射

| 级别 | GB/T 43697 | 说明 |
|------|------------|------|
| L1 | 一般数据 | 公开可访问 |
| L2 | 内部数据 | 组织内部使用 |
| L3 | 敏感数据 | 需要保护措施 |
| L4 | 高敏数据 | 严格访问控制 |
| L5 | 极敏数据 | 最高级别保护 |
