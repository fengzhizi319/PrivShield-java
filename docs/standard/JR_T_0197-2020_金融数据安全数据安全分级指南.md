# JR/T 0197-2020 金融数据安全 数据安全分级指南

## 概要

金融行业数据安全分级标准，指导金融机构进行数据分类分级。

## 数据分类

| 类别 | 说明 |
|---|---|
| 客户信息 | 身份信息、联系信息、生物特征 |
| 账户信息 | 账号、余额、交易记录 |
| 风控信息 | 信用评估、风险等级 |

## 安全分级

| 级别 | 说明 | 保护要求 |
|---|---|---|
| 1级 | 公开 | 基本保护 |
| 2级 | 内部 | 访问控制 |
| 3级 | 敏感 | 加密存储 |
| 4级 | 高敏 | 脱敏+审计 |
| 5级 | 极敏 | 端到端加密 |
