# 医疗流水线 — 产品需求文档 (PRD)

## 1. 产品概述

医疗流水线 (Medical Pipeline) 是面向医疗健康数据的端到端隐私处理流水线，将分类分级与数据脱敏整合为一体化处理流程。

## 2. 核心需求

### P0 — 必须实现
- 端到端处理：分类 → 脱敏 → 输出
- 支持常见医疗字段
- 审计日志记录
- REST 接口

### P1 — 重要
- 批量处理
- 自定义处理规则
- 处理结果缓存

### P2 — 增强
- 图像脱敏集成
- 文本-图像联动脱敏
- 处理质量评估报告

## 3. 处理流程

```
输入医疗记录
  │
  ├── 1. 字段提取
  ├── 2. 动态分类分级 (L1~L5)
  ├── 3. 敏感度判定
  ├── 4. 脱敏策略选择
  ├── 5. 执行脱敏
  ├── 6. 审计记录
  └── 7. 输出脱敏结果
```

## 4. 非功能需求

| 指标 | 目标 |
|---|---|
| 单条处理延迟 | < 100ms |
| 批量吞吐 | > 100 records/s |
| 脱敏覆盖率 | > 99% 敏感字段 |
| 审计完整性 | 100% 操作记录 |
