# 网关负载均衡 — 设计文档

## 1. 设计目标

- 统一 gRPC + REST 入口
- 支持多 Agent 实例负载均衡
- 自动故障检测和转移

## 2. 路由策略

| 策略 | 说明 | 适用场景 |
|---|---|---|
| Round Robin | 轮询 | 节点能力相同 |
| Weighted | 加权 | 节点能力不同 |
| Least Conn | 最少连接 | 长连接场景 |
| Random | 随机 | 简单场景 |

## 3. 健康检查

```
主动检查: 每 10s 调用 /actuator/health
被动检查: 连续 3 次请求失败 → 标记不健康
恢复检查: 不健康节点每 30s 探测一次
```
