# 差分隐私模块 — 产品需求文档 (PRD)

## 1. 产品概述

差分隐私 (Differential Privacy) 是数学上可证明的隐私保护机制，通过向查询结果注入 Laplace 噪声，确保单条记录的增删不会显著影响输出。

## 2. 目标用户

- 医疗数据分析：统计查询隐私保护
- 金融风控：聚合指标发布
- 政务数据开放：安全数据发布

## 3. 核心需求

### P0 — 必须实现
- Count / Sum / Mean 三种聚合操作
- Laplace 噪声注入
- ε 参数可配置
- REST + gRPC 双协议

### P1 — 重要
- 自定义灵敏度
- 预算跟踪 (BudgetAccountant)
- 查询审计日志

### P2 — 增强
- 高级组合定理 (Advanced Composition)
- Rényi 差分隐私
- 自适应 ε 分配

## 4. 数学基础

| 概念 | 公式 | 说明 |
|---|---|---|
| (ε,δ)-DP | Pr[M(D)∈S] ≤ e^ε · Pr[M(D')∈S] + δ | 差分隐私定义 |
| Laplace 机制 | M(D) = f(D) + Lap(Δf/ε) | 加法噪声 |
| 灵敏度 (Count) | Δf = 1 | 计数灵敏度 |
| 灵敏度 (Sum) | Δf = b - a | 数据范围 |
| 灵敏度 (Mean) | Δf = (b-a)/n | 随 n 递减 |

## 5. 非功能需求

| 指标 | 目标 |
|---|---|
| 单次查询延迟 | < 0.5ms |
| 线程安全 | ThreadLocalRandom |
| 随机数质量 | SecureRandom 可选 |
| 审计完整性 | 100% 查询记录 |
