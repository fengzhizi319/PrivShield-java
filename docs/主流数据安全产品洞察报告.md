# 主流数据安全产品洞察报告

## 1. 市场概览

数据安全市场快速增长，主要驱动因素：
- 法规合规要求（GDPR、个人信息保护法）
- 数据泄露事件频发
- 数字化转型加速

## 2. 产品分类

| 类别 | 代表产品 | 核心能力 |
|---|---|---|
| 数据脱敏 | PrivShield, ARX, Presidio | 字段级脱敏 |
| 差分隐私 | Google DP, OpenDP, PrivShield | 统计隐私 |
| K-匿名化 | ARX, sdcMicro | 记录匿名化 |
| 隐私计算 | SecretFlow, FATE, PrivShield | 联邦学习+MPC |
| 数据分类分级 | PrivShield, 观安信息 | 自动分类 |

## 3. PrivShield 差异化优势

1. **全栈隐私计算**: 从本地隐私到联邦学习全覆盖
2. **双协议支持**: gRPC + REST，适配多种场景
3. **三层分类分级**: 规则→NER→LLM 漏斗架构
4. **Java 生态**: 企业级 Spring Boot 集成
5. **可配置 Profile**: YAML 驱动的个性化隐私策略
