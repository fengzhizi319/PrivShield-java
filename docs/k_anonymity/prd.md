# K-匿名化模块 — 产品需求文档 (PRD)

## 1. 产品概述

K-匿名化通过泛化准标识符，确保数据集中每条记录至少与 K-1 条其他记录不可区分，从而保护个体隐私。

## 2. 核心需求

### P0 — 必须实现
- 支持数值型/分类型准标识符泛化
- K 值可配置（默认 5）
- REST + gRPC 双协议

### P1 — 重要
- Mondrian 多维分割算法
- 表格级批量匿名化
- 泛化质量评估

### P2 — 增强
- L-diversity 扩展
- T-closeness 扩展
- 增量匿名化

## 3. 泛化策略

| 类型 | 策略 | 示例 |
|---|---|---|
| 数值型 | 等宽区间 | 25 → "20-30" |
| 数值型 | 等频区间 | 25 → "Q1" |
| 分类型 | 层次泛化 | "Beijing" → "North China" |
| 分类型 | 抑制 | 罕见值 → "*" |

## 4. 非功能需求

| 指标 | 目标 |
|---|---|
| 1000 条记录匿名化 | < 100ms |
| 内存占用 | < 2x 原始数据 |
| 线程安全 | 无状态设计 |
