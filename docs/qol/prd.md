# 查询混淆模块 — 产品需求文档 (PRD)

## 1. 产品概述

查询混淆 (Query Obfuscation / Query of Life) 通过在查询结果中注入噪声记录或修改查询语句，使攻击者无法从结果中准确推断个体信息。

## 2. 核心需求

### P0 — 必须实现
- SQL 查询混淆（UNION 注入）
- 数据级噪声记录注入
- noiseScale 参数可配置
- REST + gRPC 双协议

### P1 — 重要
- 多 SQL 方言支持 (MySQL, PostgreSQL)
- 噪声记录质量评估
- 混淆审计日志

### P2 — 增强
- 自适应噪声（根据查询复杂度）
- 假名替换 (Pseudonymization)
- 查询重写优化

## 3. 非功能需求

| 指标 | 目标 |
|---|---|
| 查询混淆延迟 | < 10ms |
| SQL 解析准确率 | > 99% |
| 噪声不可区分性 | 与真实记录统计一致 |
