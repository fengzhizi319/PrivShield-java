# 动态分类分级 — 设计文档

## 1. 三层漏斗架构

### L1: 规则引擎层

- 基于 YAML 定义的规则进行匹配
- 支持正则表达式、关键词、字段名匹配
- 速度: < 0.01ms/字段
- 置信度: 0.95 (规则完全匹配)

### L2: NER 模型层

- 使用本地 NER 模型识别实体
- 支持人名、地址、机构名等实体类型
- 速度: ~5ms/字段
- 置信度: 0.7-0.9

### L3: LLM 大模型层

- 调用外部 LLM API (OpenAI/Qwen/vLLM)
- 处理复杂语义理解场景
- 速度: ~500ms/字段
- 置信度: 0.5-0.95

## 2. 分类级别

| 级别 | 说明 | 示例 |
|------|------|------|
| L1 | 公开信息 | 机构名称 |
| L2 | 内部信息 | 员工工号 |
| L3 | 敏感信息 | 手机号 |
| L4 | 高敏信息 | 身份证号 |
| L5 | 极敏信息 | 病历诊断 |

## 3. 降级机制

- 高优先级规则可覆盖低层结果
- 支持手动 override 指定分类
- 降级规则在 YAML 中定义
