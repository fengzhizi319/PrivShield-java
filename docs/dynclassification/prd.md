# 动态分类分级 — 产品需求文档 (PRD)

## 1. 产品概述

动态分类分级采用三层漏斗架构，实现数据字段的自动化分类分级：
- **L1 规则引擎**: 正则 + YAML 规则，速度最快，覆盖常见模式
- **L2 NER 模型**: 本地 NER 模型，识别命名实体
- **L3 LLM 大模型**: 远程 LLM API，处理复杂/模糊场景

## 2. 分类级别

| 级别 | 名称 | 说明 | 示例 |
|---|---|---|---|
| L1 | 公开数据 | 可公开发布 | 机构名称 |
| L2 | 内部数据 | 内部使用 | 统计报表 |
| L3 | 敏感数据 | 需脱敏 | 姓名、地址 |
| L4 | 高敏数据 | 强脱敏 | 身份证、病历 |
| L5 | 极敏数据 | 最严格保护 | 基因数据、HIV |

## 3. 核心需求

### P0 — 必须实现
- 三层漏斗分类架构
- YAML 规则引擎 (L1)
- 批量分类接口
- REST + gRPC 双协议

### P1 — 重要
- NER 模型集成 (L2)
- 分类 Profile 管理
- 分类结果缓存

### P2 — 增强
- LLM 集成 (L3)
- 自定义分类标准
- 分类质量评估报告

## 4. 非功能需求

| 指标 | 目标 |
|---|---|
| L1 分类延迟 | < 1ms |
| L2 分类延迟 | < 50ms |
| L3 分类延迟 | < 5s |
| 分类准确率 | > 90% |
| 规则覆盖率 | > 70% 常见字段 |
