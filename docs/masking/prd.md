# 数据脱敏模块 — 产品需求文档 (PRD)

## 1. 产品概述

数据脱敏是隐私计算的基础能力，对敏感信息进行实时掩码处理，防止数据泄露。

## 2. 目标用户

- 医疗健康平台：患者信息脱敏
- 金融机构：客户身份信息保护
- 政务系统：公民隐私数据脱敏

## 3. 核心需求

### P0 — 必须实现
- 支持姓名/手机/身份证/邮箱/银行卡号脱敏
- 支持字段名自动识别脱敏策略
- 提供 REST + gRPC 双协议接口
- 支持 YAML 规则自定义

### P1 — 重要
- HMAC 哈希（一致性映射）
- 批量脱敏接口
- 整记录脱敏

### P2 — 增强
- 自定义脱敏策略扩展
- 脱敏审计日志
- 性能监控指标

## 4. 脱敏规则

| 类型 | 原始值示例 | 脱敏结果 | 保留规则 |
|---|---|---|---|
| 姓名 | 张三丰 | 张**丰 | 首尾各1字 |
| 手机 | 13812345678 | 138****5678 | 前3后4 |
| 身份证 | 110101199001011234 | 110101********1234 | 前6后4 |
| 邮箱 | test@example.com | t***t@example.com | 首尾各1字符 |
| 银行卡 | 6222021234567890 | 6222********7890 | 前4后4 |

## 5. 非功能需求

| 指标 | 目标 |
|---|---|
| 单字段脱敏延迟 | < 1ms |
| 批量吞吐 | > 10,000 ops/s |
| 可用性 | 99.9% |
| 并发安全 | 线程安全 |
